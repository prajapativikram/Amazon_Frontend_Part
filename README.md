## 🔥 Project Overview

This is a **frontend clone of Amazon** built using **HTML, CSS, and JavaScript**. The project replicates the design, layout, and UI features of the Amazon website, including the navigation bar, product listing, search bar, and footer.  

##  Live Demo : https://codepen.io/prajapativikram/pen/mdNbPwG

**Note:** This project is for educational purposes only. It does **not include backend functionality** or real product data.

---

## 💡 Features

- Fully responsive Amazon-style homepage
- Navigation bar with logo, search bar, and menu items
- Product listing cards with images, titles, ratings, and prices
- Hover effects and animations for interactive UI
- Footer with Amazon-like links and sections
- JavaScript-driven carousel/slider for featured products
- Clean and modular HTML, CSS, and JS structure

---

## 🛠️ Tech Stack

- **HTML5** – Structure of the webpage  
- **CSS3** – Styling, animations, and responsive design  
- **JavaScript** – Dynamic UI components
